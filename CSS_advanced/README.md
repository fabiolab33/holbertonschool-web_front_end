# CSS Advanced Project

## 📌 Description

This project is part of the Holberton School Web Front-End curriculum. It focuses on building a fully styled webpage using advanced CSS concepts such as:

- CSS variables (custom properties)
- Typography management
- Layout techniques (flexbox, float, grid-like structures)
- Responsive-friendly units (rem)
- Pseudo-classes and pseudo-elements
- Transitions and animations
- Navigation bar styling
- Card layouts and sections
- Dark theme implementation
- Normalize.css for cross-browser consistency

The goal is to progressively build and enhance a web page by completing a series of tasks that introduce and reinforce modern CSS practices.

---

## 🎯 Objectives

By the end of this project, you will be able to:

- Use CSS custom properties effectively
- Structure CSS in a maintainable and scalable way
- Apply typography and spacing consistently
- Build reusable UI components (cards, sections, buttons)
- Implement navigation menus with hover effects
- Create layout systems using floats and containers
- Use pseudo-elements for decorative purposes
- Apply transitions and transforms for interactivity
- Implement theme variations (light/dark)


---

## 🧩 Tasks Overview

The project is divided into 32 incremental tasks:

1. Effortless scrolling behavior  
2. Basic color styling  
3. Introduction to CSS variables  
4. Font family variables  
5. Font size variables  
6. Font weight variables  
7. Google Fonts integration  
8. Line height variables  
9. Remove default link decoration  
10. Section header alignment  
11. Section tagline styling  
12. Section title styling  
13. Link pseudo-classes (hover, visited, active)  
14. Normalize CSS for browser consistency  
15. Universal box-sizing rule  
16. Container layout styling  
17. Section padding system  
18. Navbar styling and positioning  
19. Grid layout and column system  
20. Clear floats in grid layout  
21. Simplified column selectors  
22. Dark theme implementation  
23. Dark theme fixes for footer and social links  
24. Services section hover effects  
25. Button styling with borders and variables  
26. Testimonials styling with circular images  
27. Hero section styling  
28. Header and logo positioning  
29. Navbar hover underline effects using pseudo-elements  
30. Work section layout and hover interactions  
31. Decorative quote styling in testimonials  
32. Transitions and animations across components
