# Techium - Digital Agency Website

## 📌 Description

Techium is a responsive static website for a digital agency.  
This project focuses on building a multi-page website using semantic HTML5 structure, accessibility best practices, and proper organization of assets.

The project includes:
- A homepage (`index.html`)
- A style guide (`styleguide.html`)
- Multiple extended style guide versions (30, 32, 38, 39)
- Media elements such as images, video, audio, and iframe
- Navigation between sections using anchor links

---

## 🌐 Pages Overview

### 🏠 Homepage (`index.html`)
Contains the main sections of the website:
- Header with navigation menu
- Hero section
- Services
- Portfolio (Works)
- About Us
- Latest News
- Testimonials
- Contact section
- Footer with social links and legal links

---

### 🎨 Style Guide (`styleguide.html` and variants)

These pages demonstrate:
- Headings (H1–H6)
- Paragraphs and typography
- Lists (ordered, unordered, definition)
- Blockquotes
- Tables
- Details / summary elements
- Multimedia elements (video, audio, iframe)
- Address and semantic HTML elements

---

## 🧱 Technologies Used

- HTML5
- Semantic elements
- Accessibility best practices
- Media embedding (video, audio, iframe)
- SVG icons (inline)

---

## 🎯 Objectives

- Practice semantic HTML structure
- Build a multi-section webpage
- Use proper heading hierarchy
- Improve accessibility (alt attributes, titles, labels)
- Organize project files and assets correctly
- Implement navigation using anchor links
- Work with multimedia content

---

## 🚀 How to Run

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Navigate through the site using the menu links.

No installation or dependencies are required.

---

## 🧪 Notes

- All images should be placed inside the `images/` folder.
- Favicon files must remain in the root directory.
- Ensure file names match exactly (case-sensitive).
- The project is static (no JavaScript or backend required).
